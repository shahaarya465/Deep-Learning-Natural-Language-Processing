# Deep Learning for Natural Language Processing

This repository contains practical assignments of Deep Learning for Natural Language Processing (DLNLP).

## Notebooks

- **n_gram_model.ipynb**: Implementation and exploration of n-gram language models for text prediction and analysis.
- **nltk_spacy.ipynb**: Comparison and usage of NLTK and spaCy libraries for various NLP tasks such as tokenization, POS tagging, and named entity recognition.
- **shallow_networks.ipynb**: Study and implementation of shallow neural networks for natural language processing tasks.
- **PyTorch_Part_A.ipynb**: Introduction to PyTorch, covering basic tensor operations and foundational deep learning concepts.
- **PyTorch_Part_B.ipynb**: Advanced PyTorch topics, including building and training neural networks for NLP applications.
