# Deep Learning for Natural Language Processing

This repository contains practical assignments of Deep Learning for Natural Language Processing (DLNLP).

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/shahaarya465/Deep-Learning-Natural-Language-Processing.git
   ```
2. Open the notebooks in Jupyter or VS Code.

## Requirements
- Python 3.x
- Jupyter Notebook
- Deep Learning libraries (e.g., TensorFlow, PyTorch)
- NLP libraries (e.g., NLTK, spaCy)

## Usage
- Open the `.ipynb` files and follow the instructions in each notebook.
- Modify and run the code cells to complete the practicals.
