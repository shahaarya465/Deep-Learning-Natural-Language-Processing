# Deep Learning for Natural Language Processing

This repository contains practical assignments and example notebooks for a course on Deep Learning for Natural Language Processing (DLNLP).

## Notebooks

- **PyTorch_101.ipynb**: Introduction to PyTorch covering tensors, autograd, and basic model building.
- **1_n_gram_model.ipynb**: Implementation and exploration of n-gram language models for text prediction and analysis.
- **2_nltk_spacy.ipynb**: Comparison and usage of NLTK and spaCy for tokenization, POS tagging, and named entity recognition.
- **3_shallow_networks.ipynb**: Study and implementation of shallow neural networks for NLP tasks.
- **4_word_embeddings.ipynb**: Exploration of word embedding techniques (Word2Vec, GloVe) and their applications.
- **5_RNN_for_Sequence_Labeling.ipynb**: Recurrent neural network models for sequence labeling tasks (e.g., POS tagging, NER).
